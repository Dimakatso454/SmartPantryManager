Smart Pantry Manager



Project Description

Smart Pantry Manager is an Android application developed to help users manage their food items, monitor expiry dates, and reduce food waste.



Features

\-Add, edit, and delete food items.

\-Save food items using an SQLite database.

\-Search for food items by name.

\-Sort food items by name or expiry date.

\-Filter food items by expiry status.

\-Display expired, expiring soon, and fresh food items.

\-Show low stock and out of stock alerts.

\-Display a pantry summary.



Technologies Used

\- Java

\- Android Studio

\- XML

\- SQLite



How to Run the App

1\. Open the project in Android Studio.

2\. Connect an Android phone with USB debugging enabled.

3\. Click Run to install and launch the application.



Alternatively, install the generated APK file on a compatible Android phone.



Testing

The application was tested on an Android phone. The main features were checked, including adding, editing, deleting, searching, sorting, filtering, and saving food items.



Project Status
